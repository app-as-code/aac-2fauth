# Icon source

Icons are downloaded from the homarr-labs dashboard-icons collection (repository
`homarr-labs/dashboard-icons`, served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/2fauth.svg` | Default (dark logo for light backgrounds) |
| `icon-dark.svg` | `svg/2fauth-light.svg` | Light logo for dark mode |
